🔍 WebSocket 이벤트 인스펙터 (Event Stream)

📖 WebSocket 핵심 4대 이벤트 이해하기

1. ws.onopen

클라이언트와 서버 간의 HTTP Upgrade 핸드셰이크가 성공적으로 완료되어 양방향 TCP 소켓이 열렸을 때 단 1회 발생합니다.

2. ws.onmessage

서버가 보낸 텍스트(JSON) 또는 바이너리(Blob/ArrayBuffer) 데이터를 수신했을 때 실행되며 event.data로 접근합니다.

3. ws.onerror

서버 접속 불가, 네트워크 단절, 프로토콜 위반 등의 소켓 통신 오류가 발생했을 때 호출됩니다.

4. ws.onclose

클라이언트의 ws.close() 호출 또는 서버 측 종료로 연결이 닫혔을 때 종료 코드(Code) 및 사유(Reason)와 함께 발생합니다.
