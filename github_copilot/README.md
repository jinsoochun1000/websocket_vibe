# WebSocket 실시간 채팅 튜토리얼

브라우저의 WebSocket API와 Node.js의 [`ws`](https://github.com/websockets/ws) 라이브러리로 만든 가장 작은 실시간 채팅 예제입니다. 한 탭에서 보낸 메시지를 같은 서버에 연결된 모든 탭에 전달합니다.

## 준비물

- Node.js 18 이상
- npm

## 실행 방법

프로젝트 폴더에서 아래 명령을 실행합니다.

```bash
npm install
npm start
```

브라우저에서 <http://localhost:3000>을 열고, 같은 주소를 다른 탭에서도 열어 메시지가 실시간으로 전달되는지 확인합니다. 포트를 바꾸려면 `PORT` 환경 변수를 설정한 뒤 `npm start`를 실행합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 채팅 화면, 브라우저 WebSocket 연결, 메시지 입력 및 표시 |
| `server.js` | HTML 제공, WebSocket 연결 처리, 메시지 검증 및 전체 클라이언트에 브로드캐스트 |
| `package.json` | 실행 명령과 `ws` 의존성 정의 |

## 동작 흐름

1. Node.js HTTP 서버가 `index.html`을 제공합니다.
2. 페이지는 현재 페이지의 호스트에 WebSocket 연결을 엽니다. HTTPS 페이지에서는 `wss:`, HTTP 페이지에서는 `ws:`를 사용합니다.
3. 클라이언트는 JSON 형식 `{ "type": "chat", "text": "안녕하세요" }`로 메시지를 보냅니다.
4. 서버가 형식과 메시지 길이(1~500자)를 확인하고, 연결 중인 모든 클라이언트에 메시지와 시간을 전달합니다.
5. 브라우저는 서버에서 받은 메시지를 화면에 표시합니다. 메시지는 HTML로 해석하지 않고 텍스트로 렌더링합니다.

서버에서 브로드캐스트하는 채팅 이벤트 예시는 다음과 같습니다.

```json
{
  "type": "chat",
  "text": "안녕하세요",
  "time": "2026-10-04T00:00:00.000Z"
}
```

이 예제는 학습용이며 사용자 인증, 저장소, 재접속 처리는 포함하지 않습니다.
